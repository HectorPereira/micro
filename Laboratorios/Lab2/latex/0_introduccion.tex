\section{Introducción}

El presente laboratorio se desarrolla en el marco del curso de Microcontroladores, teniendo como objetivo principal la aplicación práctica de los conocimientos teóricos adquiridos sobre la arquitectura AVR y la programación en lenguaje C. A diferencia de los ejercicios iniciales, orientados al manejo individual de periféricos, esta instancia propone el diseño e integración de varios módulos funcionales que operan en un entorno de tiempo real, permitiendo comprender la interacción entre hardware y software dentro de un sistema embebido.  

\subsection{Propósito del laboratorio}

El propósito central es diseñar, programar e integrar subsistemas independientes sobre el microcontrolador ATmega328P, abordando diversas interfaces de entrada y salida, comunicación serial, control de actuadores por \textit{Pulse Width Modulation} (PWM), adquisición analógica de señales y almacenamiento no volátil mediante memoria EEPROM.  
A través de este trabajo se busca consolidar la capacidad de desarrollar proyectos embebidos que respondan de forma determinista a eventos externos y gestionen múltiples tareas concurrentes con recursos limitados.

\subsection{Objetivos}

\textbf{Objetivo general:}
\begin{itemize}
    \item Integrar y programar distintos módulos electrónicos basados en el microcontrolador ATmega328P, aplicando conceptos de arquitectura AVR, control de periféricos y desarrollo de sistemas embebidos en tiempo real.
\end{itemize}

\textbf{Objetivos específicos:}
\begin{itemize}
    \item Implementar un sistema de control cartesiano (plotter) mediante servomotores y comunicación serial.
    \item Desarrollar un sistema de detección de colores que combine medición analógica, control PWM y visualización RGB.
    \item Diseñar un piano electrónico con reproducción de notas y melodías almacenadas utilizando temporizadores e interrupciones.
    \item Construir una cerradura digital que permita el ingreso y cambio de contraseñas almacenadas en la memoria EEPROM.
    \item Aplicar principios de modularidad y diseño estructurado en C para lograr una integración eficiente entre hardware y software.
\end{itemize}

\subsection{Descripción general de los módulos}

El laboratorio se divide en cuatro implementaciones principales:

\begin{itemize}
    \item \textbf{Plotter:} sistema de control cartesiano para el movimiento coordinado de ejes y el trazado de figuras mediante servomotores.
    \item \textbf{Colores:} sensor de detección cromática basado en una fotocelda (LDR), control de servomotor para posicionamiento angular y visualización del color identificado en una tira LED WS2812.
    \item \textbf{Piano:} instrumento electrónico que reproduce notas musicales y melodías almacenadas en memoria utilizando temporizadores e interrupciones.
    \item \textbf{Cerradura electrónica:} sistema de acceso protegido mediante contraseña, con interfaz de teclado matricial, pantalla LCD y almacenamiento persistente en EEPROM.
\end{itemize}

\subsection{Competencias desarrolladas}

Durante el desarrollo de los módulos se aplicaron y fortalecieron competencias clave en el ámbito de la ingeniería mecatrónica, tales como:

\begin{itemize}
    \item Programación estructurada en lenguaje C sobre microcontroladores de arquitectura AVR.
    \item Configuración y uso de temporizadores e interrupciones para la ejecución de tareas simultáneas.
    \item Aplicación de PWM en el control de servomotores y generación de señales de audio.
    \item Implementación de comunicación serial (USART) para intercambio de datos y monitoreo del sistema.
    \item Manejo de memoria EEPROM para almacenamiento no volátil de información.
    \item Diseño de máquinas de estados para la gestión de la interfaz usuario–sistema.
\end{itemize}
