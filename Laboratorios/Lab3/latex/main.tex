\begin{abstract}
El informe presenta el desarrollo del Laboratorio 3 de Microcontroladores, orientado a la implementación de cinco módulos basados en el microcontrolador ATmega328P. 
Los módulos abarcan distintas aplicaciones del control embebido: un Plotter cartesiano, un sistema de control de temperatura con sensor LM35 y transistor TIP31C, un módulo de control de motor DC, una matriz de LEDs WS2812 y una cerradura RFID con lector RC522. 
Cada sistema integra sensores, actuadores y comunicación digital mediante periféricos como ADC, PWM, SPI, I2C, UART y EEPROM. 
El firmware fue desarrollado en C y complementado con interfaces de monitoreo en Python, demostrando la interacción entre hardware y software en sistemas de control integrados.
\end{abstract}


\textit{Palabras clave:} ATmega328P, ADC, PWM, SPI, UART, I2C, EEPROM, LM35, TIP31C, RC522, WS2812, Python, sensores, actuadores, control digital, sistemas embebidos.
